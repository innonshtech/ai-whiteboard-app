Verdict

The first demo failed because the client was shown registration and teacher login, and the tools on the board did not finish their own gestures. Since then the whiteboard code has been extended so a debug build opens on the board and Shashank’s tool list has an implementation. That code has not been signed off on the IFP panel. The 31 Oct demo is a test of the board, not a claim that the full Sprint 2 story list is done.

Do not demo a release build. Debug builds set DEMO_MODE to true and cold-start on a board named “Demo Whiteboard”. Release builds set it to false and still open license, QR login, then Class Home. The APK for 31 Oct has to be a debug (or a future demo) build, exercised on the panel by 28 Oct.

What the client said

Observation points from the demo. The client was disappointed. The next demo is 31 Oct, and the team was asked to be ready at least three days earlier.

  1. Only the whiteboard was supposed to be on screen. Teacher login and board registration were included. The client did not want those modules in this showing.
  2. Every whiteboard tool needs a real test. In that demo, no tool was working perfectly. Close did not dismiss panels. Pop-ups stayed on the screen.
  3. Shashank’s earlier list was still open. Those points are the feature table below. A second developer was requested. A dedicated tester should sit on every feature from here to the demo.
Response already in the code for point 1 and the stuck pop-ups. With demo mode on, startup skips the “Checking this panel with the school server…” splash and goes to canvas/{noteId}. License, QR, and Class Home stay in the app and are simply not the start route. Dock popovers are written to dismiss on an outside tap, a tool change, pen-down, and an explicit Close. That behaviour still has to be proven on the panel, one dialog at a time.

What the whiteboard already contains

Board engine

CapabilityWhat the teacher getsLimit to know before the demo
Infinite canvas Pinch zoom from 10% to 500%, two-finger pan, multiple pages (up to 50), dark and light ink themes, autosave into the local board file, undo and redo. Two-second load and 60 fps were never measured on the panel.
Writing tools Pen, pencil, marker, highlighter, brush. Width slider 1–50 px with stepped minus and plus. 24 preset colours, a hex field, and a colour wheel. Pressure affects brush width. Size now writes into new text and sticky notes as well as ink. Confirm on device that a selected object changes, not only the next stroke.
Two colours Tip A and tip B on the ink panel, one-tap swap. New strokes use the active tip. Existing strokes keep the colour they were drawn with. A stylus barrel button is not wired. Swap is a tap.
Erasers Standard eraser cuts a circle out of a stroke (size 8–80). Smart eraser deletes the whole object. Palm rejection ignores a large contact while a stylus is down. Palm-eraser mode turns that same large contact into a wipe. Selection eraser cuts only the selected strokes. Palm behaviour depends on the panel reporting touch size. It has to be tried with the real stylus and a resting palm.
Magic pen Rough circle, ellipse, rectangle, square, triangle, line, arrow, star, or diamond offers “Convert to shape?” half a second after lift. Yes converts, No keeps the ink, silence converts after two seconds. The mode can be turned off. It stays off while Smart Write is on. Label in the dock is Magic pen. Recognition quality on fast IFP strokes still needs a tester pass.
Shape tools Rectangle, diamond, circle, arrow, line, triangle, star, ellipse, square, hexagon, rounded rectangle. Placed shapes move, resize from handles, and recolour. These are flat shapes. 3D items are a separate isometric set.
3D solids Isometric cube, cylinder, cone, and pyramid as normal strokes. Same move, resize, colour, and erase as other shapes. This is a drawing, not a model you can orbit. Say “isometric solids” in the demo.
Math tools Geometry on the dock opens one panel for ruler, compass, protractor, set square (45°-45°-90°), and equilateral triangle. Drag a card onto the board or tap it to place and remove. Length and radius are in centimetres, the protractor arm is in degrees, and rotation can be set from the panel. Already present at the first demo. Open Geometry in the script so the tools are shown working.
Pen density Sample gap is stored in millimetres, default about 0.4 mm, and the same screen-to-world gap is used on the main board and in a split pane. Look at a slow curve at 100% and zoomed, on the board and inside a split pane. Sparse ink is a fail.
Pages Add, rename, delete (last page refused, confirm, undo), duplicate. Titles persist with the board. Copy selection, change page, paste with a small offset. While a PDF or PPT is open, page count follows the file. Rename still works. Delete does not.
Backgrounds White, dark, lined, dotted, grid, graph paper, a drawn football pitch, and a picked image. Choice is per page and sits under the ink. This is not the 15-template library (KWL, Venn, mind-map skeleton) from the user stories.
Clear all One action, one confirm, clears the focused page or the focused split pane. Undo restores that surface. The label needs to read “Clear all” in the dock and the eraser panel during the dry run.
Split screen 2, 3, 4, or 6 panes. Each pane keeps its own ink and tool. Dividers resize. Closing asks to keep the focused pane. This was broken in the first demo. Retest every layout, then close and confirm the kept ink is still there.
Documents Local PDF and PPTX open as a background. Ink is a separate layer and is not written back into the file. The PDF frame can be dragged and scaled on its own. Double-tap fits it again. Annotated PDF export writes one slide per page. Save slides is a PDF, not a PowerPoint file. Drive and OneDrive are not connected.
Images, video, web Local image insert. Google image search opens in a page and a tapped result can be placed, moved, and resized. A YouTube URL embeds in a web player. A URL can open in an in-canvas browser. Split panes can show a local video. No content library. No image rotate handle. YouTube controls are the web player’s, not a board-owned bar. Drawing on top of a live video or web view is not a separate ink layer.
OCR and equations Smart Write turns handwriting into editable text (on-device, English and Devanagari). “Extract Text” on a selected image. PDF OCR can run the current page first, shows progress, can be stopped, and the text is saved so search still works after reopen. Handwritten equations render as LaTeX and can be solved on the board. There is no lasso-then-convert button for handwriting. Equation recognition is local parsing, not a cloud vision service. A scanned PDF becomes searchable text, not a fully editable document of every page.
Flowchart and mind map Flowchart nodes with arrows that stay attached when a node moves. Mind-map branches that move as a subtree. Treat both as a first version. The dry run should drag a middle node and a branch and watch the connectors.
Stickers and emoji A fixed emoji set inserts as text. A small sticker row (star, tick, cross, thumbs-up) inserts as movable objects. Selection can move and delete them. This is a short set, not the system emoji keyboard.
Save The board autosaves locally. An explicit Save flushes that file. “Save slides” exports an annotated PDF. Export image writes one PNG of the current content. “Save to…” writes a .whiteboard JSON file on the device. There is no IWB file, no per-page PNG zip, no cloud destination, and no restore-from-backup flow.
Panel identity Each panel has Settings.Secure.ANDROID_ID as its id and a GYSH-… license checked with the school server. Help on the board shows the panel id and the license state. Demo mode never shows the license screen. The id is only on Help. Confirm with Shashank that this is the “unique key” he meant before changing the API.
Other tools already on the dock Select, lasso, hand, text, sticky note, laser, spotlight, screen shade, magnifier, bucket fill, frame, undo/redo, live-collaboration room id. Live collaboration creates a local room id. It does not sync student canvases.

Enhancements, in detail

Each block is the current behaviour, the gap the client will still feel, and the work that closes it. Items marked for 28 Oct are demo-blocking. Items marked after 31 Oct are real product work and should not be started if the dry run is still red.

1. Demo entry 28 Oct

Now. debug sets DEMO_MODE true. Cold start creates or reopens one note and navigates to the canvas. Back must not land on teacher or registration. release still starts at license.

Enhance. Add a build type named demo, with demo mode on and with shrinking turned off, so the file handed to the client is not a raw debug APK and is not a release APK that shows registration. Splash copy in demo mode must never be the school-server line.

  • Pass: install that build, force-stop, launch. First screen is an empty board.
  • Pass: system Back does not reveal QR, license, or Class Home.

2. Close and pop-ups 28 Oct

Now. The dock is supposed to dismiss on outside press, tool change, and the first pen contact. Dialogs that must have a Close control: live collaboration, command palette, help, image search, YouTube, web embed, text, sticky, rename, delete, clear, export, PDF search, Smart Write, formula card.

Enhance. A tester opens every one of those, taps the board, and taps Close. Any panel that survives is a demo-blocker. Also confirm pen-down clears the dock before the stroke is drawn, so the first line is not lost under a popover.

3. Size, across every object 28 Oct

Now. setStrokeWidth clamps 1–50 and is applied to new ink. Text and sticky notes are supposed to store that width. A selected text or shape should update in place. Eraser size is a separate slider.

Enhance. Walk pen, pencil, marker, highlighter, brush, eraser, text, sticky, and a selected rectangle. The minus and plus buttons must be large enough to hit on the panel without aiming at the slider thumb. If text under a certain size still snaps to a fixed pixel size, that snap is the bug to remove.

4. Clear all 28 Oct

Now. Clear targets the focused surface and pushes an undo snapshot.

Enhance. Confirm the button text is “Clear all” in both the dock and the eraser panel. Confirm a split pane clear does not wipe the other panes. Confirm undo after clear does not also undo an earlier page rename.

5. Split screen 28 Oct

Now. Layouts are 2, 3, 4, and 6. Weights resize columns and rows. Close keeps the focused pane instead of always keeping pane 0.

Enhance. On the panel, drag every shared edge in the 4-up and 6-up layouts. A divider that only works on the first gap is the bug from the first demo. Active pane needs a visible frame. Pen colour, eraser, and undo in pane 3 must not redraw pane 1. After close, reopen the board and confirm the kept ink was saved.

6. Magic pen and the shape set 28 Oct

Now. Recognition covers line, arrow, rectangle, square, diamond, circle, ellipse, triangle, star. Toolbar adds hexagon and rounded rectangle. Prompt delay is 500 ms, auto-convert is 2 s.

Enhance. Recognition on a 4K panel may see different point spacing than the emulator. If a slow circle is not offered, that is a threshold bug, not a missing tool. The Yes / No card must dismiss when the pen goes down again, same as the other pop-ups. Smart Write and Magic pen must not both be armed.

7. Pen density 28 Oct

Now. Gap default is about 0.4 mm and is converted with the canvas scale on both the main board and split panes.

Enhance. Compare a 10 cm curve at 100% and at 200% zoom. If split ink is still dotted, the split path is still comparing world distance to screen pixels. Fix that before adding features. Keep pressure width as it is.

8. Palm eraser and selection eraser 28 Oct

Now. A contact whose area is over 3 cm² is a palm, and only while a stylus is active. Palm-eraser mode uses that contact to erase. Selection mode restricts the standard eraser to selected ids. Star and the newer shape outlines are included in the eraser geometry.

Enhance. The IFP infrared frame often reports touch size as 0. A zero size is treated as “not a palm”, so palm eraser can silently do nothing on that hardware. The tester’s first check is whether a resting palm is detected at all. If it is not, the demo line is: palm rejection and palm erase need the panel’s touch-size data, and the toggle is there. Do not fake a pass.

9. Pages: rename, delete, copy 28 Oct

Now. Titles, delete with undo, duplicate, and a stroke clipboard live on the board snapshot.

Enhance. Long-press the thumbnail for Rename, Delete, and Duplicate. Paste should land slightly offset so it is visible. Copy across a PDF-backed board should be refused or clearly limited, because those pages are tied to the file. Relaunch is part of the test, not an extra.

10. PDF frame 28 Oct

Now. Document position and scale are stored separately from the ink camera. Drag moves the page. Corner handles scale it between 0.2 and 3. Ink is not moved with the page.

Enhance. Use a real classroom PDF, not a blank page. Check that pinch-zoom of the canvas still works when the finger starts outside the PDF, and that a drag that starts on the page does not also pan the ink. Annotations from before the move must stay where they were drawn.

11. OCR 28 Oct for the demo slice, then deepen

Now. Image OCR and PDF OCR use on-device ML Kit. PDF OCR can be stopped, prefers the current page, and the result is stored on the board so search survives reopen. Smart Write offers text after handwriting. Equations go through the local math parser and can be solved.

Enhance for the demo. One image, one handwriting line in English, one PDF page, stop, reopen, search. That is the script.

Enhance after 31 Oct.

  • Lasso or selection, then an explicit “Convert to Text”, matching story FC0027. The current offer appears on its own.
  • Hindi handwriting that actually uses the Devanagari model on the panel, plus a clear failure when Tamil, Bengali, and the other listed languages have no model.
  • “Make editable” for the rest of a scanned PDF, with a per-page progress bar that the teacher can leave and come back to.
  • Equation convert stays honest: it is on-device structure, not a cloud vision API.

12. Backgrounds 28 Oct Templates after

Now. Football pitch is drawn (field, lines, centre circle), plus white, dark, lined, dotted, grid, graph, and a picked image, per page.

Enhance for the demo. Football on page 1, graph paper on page 2, both survive relaunch, ink above both.

Enhance after 31 Oct. Story FC0029 asks for at least 15 subject templates (KWL, Venn, table, mind-map skeleton) with a preview, applied as a background layer. Backgrounds are not that library.

13. Save slides 28 Oct as PDF

Now. Explicit Save flushes the board JSON. Save slides exports an annotated PDF, one page per board page, including background and ink. PPTX in this app is a reader only.

Enhance. The button text must say PDF so the client is not shown a PowerPoint promise. Open the exported file on the panel and check page order, titles, and that a dark page stays dark. A later enhancement is a real PPTX writer and per-page PNG files inside a zip (story FC0033).

14. Two-colour pen 28 Oct

Now. Two swatches and a swap. Active tip colours new strokes only.

Enhance. Swap has to be one hit on the panel. After swap, the pen, marker, and highlighter should all pick up the active tip. Highlighter transparency must not turn the second colour opaque.

15. Stickers and emoji 28 Oct, small set

Now. Fixed emoji picker and four stickers, movable and deletable.

Enhance. They must land on the current page, including the active split pane, and they must export in the PDF slides. Growing the catalogue can wait.

16. Localisation Do not demo yet

Now. uiLocaleTag toggles between en and hi and is stored with the panel session. values-hi/strings.xml contains the app name plus clear, save, save-slides, magic pen, and close. No screen calls stringResource. Tool names and dialogs are still Kotlin literals in English.

Enhance. Wire the whiteboard chrome and dialogs to those strings, finish the Hindi set for tools, pages, clear, save, and errors, and recreate the activity when the toggle changes. Class Home can stay English because the demo build does not show it. Until a tester can read the dock in Hindi and switch back, this item stays off the script. More Indian languages are a later pass.

17. 3D shapes 28 Oct only if the dry run of items 1–14 is clean

Now. Cube, cylinder, cone, pyramid render as isometric paths with the same handles as flat shapes.

Enhance. No 3D engine for this demo. If the client asks to rotate in space, the answer is that these are classroom isometric drawings. Hit-testing and erase must match the visible outline, including the ellipse caps on cylinder and cone.

18. Flowchart Same gate as 3D

Now. Process, decision, and terminator nodes, with arrows whose ends stick to nodes. Moving a node moves its arrows. Parent and child ids live on the stroke and stay off the ink hot path.

Enhance. Dragging the middle of three nodes is the pass. Also delete a node and confirm its arrows go with it. Also undo that delete. If arrows drift by more than a few pixels, hide the tool in the demo build rather than showing a broken connector.

19. Mind map Same gate as 3D

Now. A centre topic, add-branch, children laid out to the sides, dragging a branch moves its subtree.

Enhance. Centre plus four branches, then drag one. Add a child to a child and confirm the grandchild moves too. This shares the connector model with the flowchart, so one fix should serve both.

20. Unique key Verify, do not rebuild

Now. Panel id is the Android id. License key format is the GYSH key checked by PanelApi.verifyLicense. Help shows both. Demo mode does not remove that code. It only skips the screen.

Enhance. On the demo panel, open Help and read the id aloud once in the dry run so the presenter knows where it is. If Shashank meant a school license visible on the board, that line is already the place. If he meant a per-board key or a QR for students, that is new work and it misses 31 Oct unless he confirms this week.

21. Backup and recovery After 31 Oct

Now. Room holds the note. The board snapshot is a local JSON file. Export can write a .whiteboard file under app storage. Clearing app data loses the board. There is no import of that file back onto a fresh install.

Enhance.

  • Export a single archive the teacher can see in the panel’s files: board JSON, images, custom backgrounds, and the open document path.
  • Import that archive onto the same panel after a data clear, and onto a second panel.
  • A failed import leaves the current board untouched.

Until import exists, the demo sentence is “this lesson is stored on this panel.”

22. Cloud save and sync After 31 Oct

Now. Nothing talks to Drive, OneDrive, or Dropbox. Offline mode is “the file is local,” not a sync queue. Version history is undo on one device.

Enhance, matching stories FC0035 and FC0087. Connect one provider first (Google Drive), save the same archive as backup, and pull it back. Version history is a list of those uploads, not a second product. Offline edits queue until the panel has a network. Do not start this while split, PDF, and pop-ups are still unverified.

23. Ruler and protractor 28 Oct, already built

Now. Ruler, compass, protractor, set square, and equilateral triangle sit in the Geometry panel. They drag on, rotate, show centimetres and degrees, and a line can be drawn along the ruler edge. The panel sets size, rotation, and the protractor arm.

Enhance. Put them in the dry-run script so they are not forgotten. Check the centimetre scale against a known length on the panel. DPI on an IFP is often wrong, and a “10 cm” line that is obviously not 10 cm will be noticed.

Tester script for 28 Oct

One pass, on the IFP, by the dedicated tester. A step fails if the gesture does not finish, a panel stays up, or the result is gone after leaving the board and coming back.

  1. Install the demo build. Force-stop. Launch. The first screen is an empty board. Back does not show registration or a teacher.
  2. Open the dock, image search, YouTube, text, sticky, help, clear, and export. Tap the board. Each one closes. Tap Close on each one as well.
  3. Draw with the pen. Increase and decrease size. Swap the two colours and draw again. Magic-pen a circle: try Yes, and on a second shape wait two seconds.
  4. Place a triangle, a star, a hexagon, and a rounded rectangle. Move and resize each.
  5. Open Geometry. Drag out the ruler and draw a line. Set the protractor arm and mark an angle. Draw a compass circle and read the centimetres. Place the set square and the triangle.
  6. Turn on palm eraser and wipe. Turn on selection eraser and confirm an unselected stroke is untouched.
  7. Add three pages. Rename them. Copy strokes from page 1 to page 2. Delete page 3. Leave the board and reopen. Names and the copied ink are still there.
  8. Set page 1 to the football ground. Draw on it. Save. Save slides. Open the PDF and match both the pitch and the ink.
  9. Open a one-page PDF. Shrink it and move it. The stroke beside it stays. Run OCR, stop it once, run it again, reopen, and search for a word on that page.
  10. Split into two panes. Draw in both. Resize the divider. Split into four and drag an inner edge. Close and keep the focused pane. The kept ink is still there.
  11. Place one emoji and one sticker. Move them. Clear all. Undo. The ink returns.
  12. Only if the steps above passed: isometric cube, a three-node flowchart with a drag, and a mind map with a dragged branch.
Fail closed. A tool that fails this script is removed from the 31 Oct path or fixed before 29 Oct. It is not explained live as “almost working.” That is what disappointed the client the first time.
