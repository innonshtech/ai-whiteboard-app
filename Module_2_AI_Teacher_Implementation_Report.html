2. 📊 AI PPT Generator (Editable Slide Deck & PPT/PDF Exporter)

Feature Scope: Generates editable slide presentations directly on the whiteboard canvas. Teachers can present slide-by-slide or edit text/diagrams using their stylus, then export the presentation as .pptx or .pdf.

  • Canvas Rendering: Generates 16:9 aspect ratio Slide Frames laid out horizontally across the infinite canvas.
  • Presentation Mode: Fullscreen presenter bar on the IFP panel with Next / Previous Slide controls and live ink annotation overlays.
  • Export Engine: One-tap export to .pptx (via Apache POI) or .pdf (via Android PdfDocument rendering).

Feature Scope: Provides explanations for any concept on the canvas at 3 complexity levels (Beginner, Standard, Advanced) using real-world examples, storytelling, or analogies.

  • Trigger: Teacher circles or lasso-selects any text/ink on the board and selects "AI Explain".
  • Canvas Placement: Places an explanation callout card next to the selected concept.

4. 📝 AI Quiz Generator (Interactive On-Board Assessment)

Feature Scope: Generates customizable quizzes with multiple question formats (MCQ, True/False, Fill in the Blanks, HOTS [Higher Order Thinking Skills], Descriptive, and Difficulty Levels).

  • Teacher Reveal Button: Tapping "Show Answer & Solution" on the IFP panel reveals answer keys with step-by-step reasoning.
  • Interactive Grading: Students write answers with stylus on the IFP, and teacher taps "Grade Ink with AI" to evaluate responses live.

5. 📄 AI Worksheet Generator (Printable Homework & Practice Papers)

Feature Scope: Creates printable worksheets, practice papers, and homework sheets complete with student headers, instructions, marks distribution, and answer keys.

6. 🗺️ AI Mind Maps (Interactive Concept Maps, Flowcharts & Timelines)

Feature Scope: Generates vector mind maps, flow charts, historical timelines, and relationship maps from any topic or selected board notes.

  • Vector Synthesis: Central Topic Node → Sub-topic Nodes → Vector Connecting Arrows.
  • Stylus Expansion: Double-tapping any node on the IFP panel asks AI to expand that branch into deeper sub-nodes.

7. 🎨 AI Diagram Generator (Text to Labeled, Editable Diagrams)

Feature Scope: Converts text prompts (e.g. "Human Digestive System", "Solar System", "Electric Motor", "Plant Cell") into fully labeled, interactive, and editable diagrams directly on the canvas.

PPTX Slide Deck Exporter Engine

class PptxExporter @Inject constructor(@ApplicationContext private val context: Context) {
    fun exportDeckToPptx(deck: PresentationDeck, outputFile: File) {
        val ppt = XMLSlideShow()
        for (slideData in deck.slides) {
            val slide = ppt.createSlide()
            // Add Title Box
            val titleBox = slide.createTextBox()
            titleBox.anchor = java.awt.Rectangle(50, 50, 600, 50)
            val p = titleBox.addNewTextParagraph()
            val run = p.addNewTextRun()
            run.text = slideData.title
            run.fontSize = 28.0
            
            // Add Bullet Points
            val bodyBox = slide.createTextBox()
            bodyBox.anchor = java.awt.Rectangle(50, 120, 600, 300)
            for (bullet in slideData.bulletPoints) {
                val bp = bodyBox.addNewTextParagraph()
                bp.isBullet = true
                val brun = bp.addNewTextRun()
                brun.text = bullet
                brun.fontSize = 18.0
            }
        }
        FileOutputStream(outputFile).use { ppt.write(it) }
    }
}

Radial Mind Map Layout Algorithm

fun calculateMindMapLayout(rootNode: MindMapNode, center: Offset): List<Stroke> {
    val strokes = mutableListOf<Stroke>()
    val numBranches = rootNode.children.size
    val radius = 300f
    
    // Draw Root Node
    val rootStroke = Stroke(
        strokeType = StrokeType.STICKY_NOTE,
        points = listOf(center),
        text = rootNode.title,
        colorValue = 0xFF3ECF8E.toInt() // Brand Green
    )
    strokes.add(rootStroke)
    
    // Position Children Radially
    rootNode.children.forEachIndexed { i, child ->
        val angle = (2 * Math.PI * i / numBranches).toFloat()
        val childPos = Offset(
            x = center.x + radius * kotlin.math.cos(angle),
            y = center.y + radius * kotlin.math.sin(angle)
        )
        // Add connecting arrow stroke
        strokes.add(Stroke(
            strokeType = StrokeType.ARROW,
            points = listOf(center, childPos),
            colorValue = 0xFF898989.toInt()
        ))
        // Add child node stroke
        strokes.add(Stroke(
            strokeType = StrokeType.STICKY_NOTE,
            points = listOf(childPos),
            text = child.title,
            colorValue = 0xFFFFE66D.toInt() // Yellow
        ))
    }
    return strokes
}

2D Cartesian Function Plotter Path Generator

fun generateCartesianGraphPath(
    function: (Float) -> Float,
    xMin: Float = -10f,
    xMax: Float = 10f,
    scale: Float = 40f, // Pixels per unit
    origin: Offset
): Path {
    val path = Path()
    var isFirst = true
    var x = xMin
    while (x <= xMax) {
        val y = function(x)
        val screenX = origin.x + x * scale
        val screenY = origin.y - y * scale // Invert Y for screen space
        
        if (isFirst) {
            path.moveTo(screenX, screenY)
            isFirst = false
        } else {
            path.lineTo(screenX, screenY)
        }
        x += 0.1f
    }
    return path
}

Voice Command Intent Parser

class VoiceCommandParser @Inject constructor() {
    fun parseCommand(transcript: String): VoiceIntent {
        val lower = transcript.lowercase()
        return when {
            lower.contains("create quiz") || lower.contains("make a quiz") -> VoiceIntent.CreateQuiz
            lower.contains("next slide") -> VoiceIntent.NextSlide
            lower.contains("previous slide") -> VoiceIntent.PreviousSlide
            lower.contains("explain again") || lower.contains("explain this") -> VoiceIntent.ExplainSelection
            lower.contains("generate homework") || lower.contains("worksheet") -> VoiceIntent.CreateWorksheet
            lower.contains("translate to hindi") -> VoiceIntent.Translate("hi")
            else -> VoiceIntent.Unknown(transcript)
        }
    }
}

5.2 Detailed How-To Plan for Each of the 11 AI Services

1. 📘 AI Lesson Planner on Canvas

  1. Teacher taps "AI Lesson Planner" on the IFP dock.
  2. Prompt modal collects Topic, Grade Level, and Duration.
  3. CanvasViewModel calls Gemini API and receives structured JSON.
  4. Generates a master StrokeType.FRAME titled "Lesson Plan: [Topic]" with 5 nested card objects arranged vertically.
  5. Teacher can drag, edit, or reorder any card using the stylus.

2. 📊 AI PPT Generator & Slide Deck Engine

  1. Teacher requests a 5-slide deck on a topic.
  2. Generates 5 horizontal 16:9 Slide Frames (StrokeType.FRAME) on the canvas separated by 40dp gaps.
  3. Presentation Mode: Fullscreen toolbar appears with Next Slide / Prev Slide buttons, smoothly panning canvas viewport from slide to slide.
  4. Export: One-click export button calls PptxExporter (Apache POI) to generate .pptx or .pdf.

3. 💡 AI Explain (3-Tier Conceptual Explainer)

  1. Teacher uses Lasso to select any handwritten text or drawing on the board.
  2. Floating Lasso bar shows "AI Explain" → Selects level (Beginner, Standard, Advanced) and style (Analogy, Story, Real World).
  3. Renders a callout card alongside the selected concept with styled markdown text.

4. 📝 AI Quiz Generator & Interactive Grading

  1. Teacher generates a quiz (MCQ, True/False, Fill in Blanks, HOTS).
  2. Renders interactive question cards on the canvas.
  3. Show/Hide Answer: Teacher taps a button on the card to reveal answer keys.
  4. AI Ink Grading: Students write answers on the IFP with stylus; teacher taps "Grade Ink with AI", which crops handwritten answer, runs OCR, and displays evaluation feedback.

5. 📄 AI Worksheet Generator (Printable A4 Layout)

  1. Teacher requests a homework sheet or practice paper.
  2. Creates an A4-proportioned Canvas Frame (210mm × 297mm) containing formatted headers, mark distributions, and questions.
  3. Integrated with Android PrintManager to print directly to a classroom network printer.

6. 🗺️ AI Mind Maps & Vector Concept Trees

  1. Teacher enters a topic (e.g. "Photosynthesis").
  2. Radial Layout Algorithm calculates node coordinates in World Space:
    xn = xcenter + R · cos(θn), yn = ycenter + R · sin(θn)
  3. Renders central topic box, sub-topic sticky notes, and connecting arrow strokes (StrokeType.ARROW).
  4. Double-tapping any node requests Gemini to expand that specific branch.

7. 🎨 AI Diagram Generator with "Hide Labels" Quiz Mode

  1. Teacher requests a diagram (e.g., "Human Digestive System").
  2. Generates vector paths / illustration + callout line pointers + text label blocks.

  1. Teacher circles a handwritten math equation (∫ x2 dx or y = x2 - 4).
  2. ML Kit / Gemini parses formula → Symja evaluates step-by-step algebra.
  3. Plots 2D Cartesian function graph curve directly on canvas using Canvas.drawPath().

9. 📚 AI Summarizer

  1. Teacher selects a region of board notes → Taps "AI Summarizer".
  2. Generates 4 tabbed canvas cards: Revision Notes, Interactive Flash Cards, Formula Sheet, Exam Key Points.

  1. Microphone HUD stays docked in bottom corner of IFP panel.
  2. Listens for voice triggers ("Create a 5-question quiz on Motion", "Next slide", "Explain again", "Translate to Hindi").
  3. Speech-to-Intent parser directly triggers CanvasViewModel methods hands-free.

5.3 Fallback & Offline Operational Strategy

  • Online Mode: Uses Google Gemini 1.5 Flash / Pro API for full multimodal reasoning.
  • Offline Mode: Automatically falls back to Google ML Kit for local handwriting OCR and Symja Engine for math solving when disconnected.
  • Non-Destructive Canvas History: All AI-placed canvas elements are recorded in the CanvasViewModel Undo/Redo stack, allowing teachers to revert any AI action with 1 tap.
